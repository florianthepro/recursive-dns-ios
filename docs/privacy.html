App-Daten

Der Entwickler erhebt, übermittelt, speichert oder analysiert über die App keine personenbezogenen Daten. Die App enthält keine Benutzerkonten, Werbung, Telemetrie, Analyse-SDKs, Cloud-Synchronisierung oder Tracking.

DNS-Kommunikation

Die App sendet DNS-Anfragen direkt an Root-, TLD- und autoritative Nameserver. Die kontaktierten Server können technisch die IP-Adresse des Internetanschlusses, Zeitpunkt, Domainname, Datensatztyp und Verbindungsdaten wahrnehmen. Der Entwickler erhält diese Daten nicht. Die Betreiber der jeweiligen Nameserver sind für ihre eigene Verarbeitung verantwortlich.

Lokaler Cache

Antworten werden entsprechend ihrer TTL vorübergehend im Arbeitsspeicher der Erweiterung gespeichert. Der Cache wird nicht an den Entwickler oder Dritte übertragen und endet spätestens, wenn iOS den Prozess beendet.

GitHub-Support

Bei einem freiwilligen öffentlichen GitHub Issue verarbeitet GitHub die eingegebenen Inhalte, den Benutzernamen und technische Daten. Keine vertraulichen Informationen veröffentlichen. Es gilt die Datenschutzerklärung von GitHub. Eine Löschung eigener personenbezogener Inhalte kann über ein neues Issue beantragt werden.

Rechte

Soweit der Verantwortliche personenbezogene Daten verarbeitet, bestehen nach den gesetzlichen Voraussetzungen Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung, Datenübertragbarkeit und Widerspruch. Beschwerden können an das Bayerische Landesamt für Datenschutzaufsicht gerichtet werden.

Apple

Beim App-Download kann Apple eigenständig Daten verarbeiten. Es gilt die Datenschutzrichtlinie von Apple.
